# Logos des partenaires

Déposer ici les fichiers image des partenaires institutionnels, puis remplacer
l'URL correspondante par le chemin local dans le tableau `partenaires`
en tête de `src/pages/index.astro`.

Exemple : `logo: '/logos/partenaires/ligue-idf.png'`

Format conseillé : PNG à fond transparent, 400 px de large environ.

Tant qu'un logo est absent, la page affiche le nom du partenaire à sa place.
